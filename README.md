# Vinos Farms

Open index.html in a browser to preview the website. No installation or build is required.

| To change | Edit |
| --- | --- |
| Page text, CEO profile, captions or location | index.html |
| Colours, type and layout | styles.css |
| Farm photographs | images/ (keep filenames or update the image paths in index.html) |

Use the comment below the CEO section to add dated achievements when confirmed. The map searches for the farm’s Plus Code using Ejisu, Ghana as its locality.

For GitHub Pages, choose Settings → Pages → Deploy from a branch → main → / (root).
